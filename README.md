## Contents
| File | Purpose |
|------|---------|
| `index.html` | The entire site — HTML, CSS, JS in one file. |
| `SUPABASE_SETUP.md` | Step-by-step to connect the registration form. |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is. |

## Quick start
1. Open `index.html` in a browser to preview.
2. Wire up the form → follow **[SUPABASE_SETUP.md](SUPABASE_SETUP.md)** (2 values to paste).

## Deploy to GitHub Pages
1. Push this repo to GitHub (`koreayjk/mc2026`).
2. Repo **Settings → Pages**.
3. **Source:** *Deploy from a branch* → Branch: `main` (or your default) → `/ (root)` → **Save**.
4. Live in ~1 min at `https://koreayjk.github.io/mc2026/`.

## Design
- **Colors:** navy `#0c1c34` · orange `#f26722` · cream `#f3efe6`
- **Type:** Anton (impact display) · Permanent Marker ("Conference" wordmark) · Barlow Condensed (headings) · Inter (body)
- Hero built from layered SVG (sunset gradient + mountain ridges + outstretched-arms silhouette) — no external image files, so it loads instantly and never breaks.
