# SVM Mission Conference 2026 — Landing Page

**Called. Equipped. Sent.** · Ignite your faith. Impact the nations.

A single-file, responsive landing page for the **SVM Mission Conference 2026**, with a
live registration form backed by Supabase.

- 📅 **Friday, November 13, 2026 · 7:00 PM**
- 📍 **Texas A&M University, Aggie Park (Wood Stage), College Station, TX**
- 🎯 For youth & young adults
- 🏛 Hosted by **IM Mission Foundation Group Corp**
- ✳️ **SVM** — Student Volunteer Movement, since 1886

## Contents
| File | Purpose |
|------|---------|
| `index.html` | The entire site — HTML, CSS, JS in one file. |
| `SUPABASE_SETUP.md` | Step-by-step to connect the registration form. |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is. |

## Quick start
1. Open `index.html` in a browser to preview.
2. Wire up the form → follow **[SUPABASE_SETUP.md](SUPABASE_SETUP.md)** (2 values to paste).

## Deploy to GitHub Pages
1. Push this repo to GitHub (`koreayjk/mc2026`).
2. Repo **Settings → Pages**.
3. **Source:** *Deploy from a branch* → Branch: `main` (or your default) → `/ (root)` → **Save**.
4. Live in ~1 min at `https://koreayjk.github.io/mc2026/`.

## Design
- **Colors:** navy `#0c1c34` · orange `#f26722` · cream `#f3efe6`
- **Type:** Anton (impact display) · Permanent Marker ("Mission Conference" wordmark) · Barlow Condensed (headings) · Inter (body)
- Hero is a photograph (`assets/images/hero.jpg`) under a navy duotone wash, with a smaller `hero-sm.jpg` preloaded for phones.
- The event name always reads **SVM → Mission Conference → 2026**: brand first, descriptor second, year last.
- Fixed English for the three-part call: **Mobilize · Train · Send**.
